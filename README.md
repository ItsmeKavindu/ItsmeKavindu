### ✨ Key Features
- 🗺️ Browse destinations and view destination details
- 📅 Create and manage personalized travel itineraries
- 🔐 User registration and secure login
- 🔑 Password hashing using **bcryptjs**
- 👤 User profile management
- ⭐ Destination reviews and feedback
- 🖼️ Profile image upload functionality
- 🛡️ Administrative moderation and management
- 📊 Admin dashboard support for reviews and statistics

